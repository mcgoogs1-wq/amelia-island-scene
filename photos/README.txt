YOUR OWN BANNER PHOTOS
======================

Drop photos of Amelia Island into this folder and they'll be mixed into the
rotating banner at the top of the site, alongside the Wikimedia ones.

How to add some
---------------
1. Copy photos into this "photos" folder (Finder is fine). JPG, PNG, HEIC
   (iPhone) and WebP all work.
2. Give each file a short descriptive name, because the name becomes the
   caption on the site:   sunset-at-main-beach.jpg  ->  "Sunset at main beach"
3. In GitHub Desktop, click "Commit to main", then "Push origin".
   The site rebuilds within a few minutes and starts using them.

Good to know
------------
- Use LANDSCAPE (wider than tall) photos. The banner is a wide strip, so
  portrait photos are skipped automatically.
- Don't worry about size: each photo is shrunk to a web-friendly copy for the
  site. The originals here stay untouched.
- Hidden phone data such as the GPS location is removed from the web copy.
- To remove a photo from the rotation, delete it from this folder and push.
- Every 4th day is a "your photos" day: the banner shows one of your photos,
  cycling through them. The other days use Wikimedia photos. To change the
  cadence, edit own_photos_every in config.json (2 = every other day).
